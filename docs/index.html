Planned endpoints (base path /api/v1)
Method Path Purpose
GET /events/{eventId}/tickets List tickets (empty list when none)
POST /tickets Create a ticket (422 on invalid input)
POST /tickets/{ticketId}/qr-jobs Request QR generation (idempotent)
GET /qr-jobs/{jobId} Poll job status
GET /tickets/{ticketId}/qr Get active QR code
POST /qr-scans Validate a scan at the gate
POST /analytics Record telemetry ping
